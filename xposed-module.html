Xposed vs LSPosed (short)

Classic Xposed is the API name people still type. On current rooted phones the runtime is usually LSPosed (Zygisk). Mirage installs as an LSPosed module. Enable it, select each target app in scope, reboot.

  1. Root with Magisk or KernelSU — Helper zip first
  2. Install official APK v21.38
  3. LSPosed Manager → Modules → Mirage Spoofer on → tick apps
  4. Reboot, allow root, create profiles

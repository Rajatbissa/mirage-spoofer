Features

Har feature ke steps aur poori screenshot. Image cut nahi hogi.

1-click bulk creator

Stop typing IMEI by hand. Mass-create profiles, then assign them in Home / Group.

Manual IMEI typing band. Profiles mass generate, phir Home/Group me assign.

01

Open Bulk Creator

Tap Bulk on Home and set the count — 10, 50, or 100+ profiles at once.Home se Bulk pe tap. Count set karo.

02

Unique IDs, automatic

Each profile gets its own IMEI, Android ID, MAC, SIM serial, and Ad-ID.Har profile ke IDs alag generate hote hain.

03

Save to a group

Store profiles in a group and assign a target app to use them right away.Group me save karke target app assign karo.

04

Reuse later

Select or restore the same profile later — no repeat setup.Same profile baad me restore/select. Repeat kaam nahi.

Instant restore

Deleted a profile by mistake? Backup already lives in the app.

Delete ho gaya to tension nahi — backup app ke andar hai.

01

Backup is automatic

A backup is ready as soon as you create profiles. No extra tool.Profiles create hote hi backup ready.

02

Tap Restore

After a delete, Restore brings the profile back in one tap.Delete ke baad Restore — one-tap wapas.

03

IDs stay the same

The restored profile keeps the same IDs so your workflow is not broken.Restored profile pe pehle wale IDs rehte hain.

04

Safe loop

Test, delete, restore — data stays safe and work continues.Test, delete, restore — data safe, kaam chalta rehta hai.

Floating widget

Switch profiles from an overlay while you stay inside the target app.

Target app ke andar se profile switch — overlay se.

01

Turn the widget on

Enable the floating widget in Mirage and allow overlay permission.Widget on karo, overlay permission allow karo.

02

Open the target app

Launch the app you want the identity on. The widget stays on screen.Target app kholo. Widget screen pe rehta hai.

03

Switch profile

Change profile from the overlay — no need to close and reopen the app.Overlay se profile badlo. App band karne ki zarurat nahi.

04

GPS + RTC

Timezone / clock follow the profile location. Isolation is built in — no extra hide-list app.Location ke saath timezone sync. Extra hide-list app nahi.

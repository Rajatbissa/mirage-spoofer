Magisk module: Mirage Helper zip

The official Magisk module is the Helper zip. Open Magisk → Modules → Install from storage → select Helper v12 → reboot. The APK is not a Magisk module; the zip is.

How to flash the Magisk module

  1. Download Helper v12 from the download page.
  2. Open Magisk → Modules.
  3. Tap Install from storage and select the zip.
  4. Reboot. Confirm the module is enabled.
  5. Then install the APK and set LSPosed scope.

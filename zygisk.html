Zygisk for Magisk + LSPosed

Zygisk is Magisk’s inject layer. Official LSPosed for Magisk needs Zygisk on. Then flash Mirage Helper and enable the app in LSPosed.

Magisk settings me Zygisk ON. Phir LSPosed, phir Helper, phir APK.

Download APK + Helper Setup Telegram group

Zygisk checklist

  • Magisk → Settings → Zygisk = on
  • Reboot
  • LSPosed manager opens
  • Helper module installed
  • Mirage enabled in LSPosed scope

If LSPosed will not open, fix Zygisk / LSPosed first. Mirage cannot hook without it.

KernelSU root for Mirage Spoofer

KernelSU is a supported root path. Flash the same official Helper zip as a KernelSU module, reboot, install the APK, enable LSPosed. You do not need Magisk if KernelSU is already your root.

KernelSU users: Helper zip KSU module ki tarah flash karo, phir APK.

Download APK + Helper Setup Telegram group

KernelSU install order

  1. Device rooted with KernelSU (manager app installed).
  2. Install LSPosed for KernelSU. Reboot.
  3. KernelSU → Modules → install Helper zip. Reboot.
  4. Install Mirage Spoofer v21.39.
  5. LSPosed → enable Mirage → tick target apps.

Skip the module and the APK can crash. Official files only.

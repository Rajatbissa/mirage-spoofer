Spoof location (GPS)

Mirage Spoofer lets you spoof location on rooted Android. Open a profile, pick coordinates on the map (or search a city), save, then switch. Target apps in LSPosed scope see that GPS — not the phone's real pin.

Profile me map se location set karo, switch karo. Apps us GPS ko dekhti hain.

How location spoof works

  1. Turn on GPS / location spoof for that profile.
  2. Search or tap the map, then save.
  3. Enable Mirage in LSPosed for the target app.
  4. Switch the profile from Home or the floating widget.

Location alone can look inconsistent if the clock still shows your home region. Use spoof location with timezone so RTC follows the same pin.

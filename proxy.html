Proxy connect

Proxy connect is per profile. Enter host, port, type (HTTP / SOCKS), and optional user/pass, then enable proxy. When you switch to that profile, the Helper turns the proxy on. A new profile starts with proxy off so credentials do not bleed.

Har profile ka apna proxy: host, port, type, login. Switch pe connect. Nayi profile pe proxy off rehti hai.

What proxy connect does

  • Routes target-app traffic through your proxy so you can spoof IP.
  • Uses a hidden tunnel path — see VPN — so apps do not flag a VPN icon.
  • Works with spoof location and timezone. Match proxy country to the GPS pin.

You bring the proxy server. Mirage does not sell a VPN subscription. Helper + LSPosed must be installed first.

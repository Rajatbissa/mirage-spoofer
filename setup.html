Setup

Get started with Mirage Spoofer — installation and configuration on rooted Android.

Rooted Android. Helper zip pehle, phir APK, phir LSPosed.

Download files Official Telegram

Prerequisites

Rooted Android

Magisk or KernelSU.

LSPosed

Zygisk module for hooks in target apps.

Helper module

Install before the APK or the app can crash.

Backup first

ROM and important data before you start.

Installation steps

Step 1 — Helper root module

  1. Download the official Helper zip from the download page.
  2. Install it in Magisk or KernelSU as a module.
  3. Reboot.

Step 2 — Install Mirage Spoofer

  1. Download Mirage Spoofer v21.38 from this site or GitHub.
  2. Install the APK. Allow unknown sources if Android asks.
  3. Open the app and allow root.

Step 3 — Enable in LSPosed

  1. Open LSPosed Manager → Modules.
  2. Enable Mirage Spoofer.
  3. Select each target app in scope.
  4. Reboot.

Step 4 — Account

  1. Register or log in with email.
  2. License and device bind (1 account = 1 device) apply after login.

Step 5 — First profile

  1. Create or bulk-create a profile.
  2. Pick a target app and switch from the floating widget.
  3. Force-stop the target app, then open it again.

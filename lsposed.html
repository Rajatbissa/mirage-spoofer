Enable Mirage Spoofer in LSPosed

Mirage Spoofer is an LSPosed / Xposed-style module on rooted Android. After you install the Helper root module and the APK, turn the module on and choose which apps sit in scope.

LSPosed me module on karo, target apps scope me select karo, reboot.

Steps

  1. Install Helper zip, reboot, then install official APK from Download.
  2. Open LSPosed Manager → Modules → enable Mirage Spoofer.
  3. Open the module → select target apps (the apps that should see spoofed identity).
  4. Reboot. Open Mirage Spoofer and allow root.

LSPosed Manager can also check for updates via the GitHub app_update.json on the official releases.

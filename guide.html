How to install and use

Root, Helper module, spoofer setup, and RTC — short official guide.

Root, root module, spoofer setup, aur RTC — short official guide.

Install (4 steps)

01

Helper root module

Flash / install the Helper zip in Magisk or KernelSU first. This root module prepares the environment.

Pehle Helper zip Magisk ya KernelSU me install karo.

02

Mirage APK

Install the v21.38 APK over the official app. Allow root when asked.

v21.38 APK official app ke upar. Root permission allow karo.

03

Login / register

Create an account or log in. Profile should save — email, status, and expiry appear on Profile.

Account banao ya login karo. Email, status, expiry Profile pe dikhegi.

04

Create and switch

Make profiles with Bulk Creator, pick a target app, switch from the floating widget. Restore brings backups back.

Bulk se profiles, target app select, widget se switch. Restore se backup wapas.

How to use

From login to widget switch — each step is in a box.

Login se lekar widget switch tak — har step box me detail hai.

01

Open app & login

Open Mirage. Log in if you already have an account, or register. Email, status, and expiry should show on Profile.Mirage kholo. Account hai to login, naya hai to register.

02

Create bulk profiles

Use Bulk Creator to make many unique profiles in one tap. Each gets its own IMEI, Android ID, and MAC.Bulk Creator se ek tap pe kai unique profiles.

03

Select a target app

Choose the app you want the identity on from Home / Group. The profile applies only to that selected app.Home/Group se target app banao. Sirf selected app pe apply.

04

Switch from the widget

Keep the overlay widget on. Change profile from inside the target app — no need to close and reopen it.Overlay widget on rakho. App band karne ki zarurat nahi.

05

Backup / restore

If a profile is deleted, Restore brings it back in one tap. Your data stays safe while you work.Delete ho to Restore se one-tap wapas.

06

Plan expire / recharge

When a plan ends you can still open the app and Profile. Home / Group stay browsable. Recharge unlocks full access again.Plan khatam ho to bhi app khul sakti hai. Recharge ke baad full access.

Root

Mirage Spoofer runs on rooted Android. Magisk and KernelSU are both supported. Allow root when the app asks. The workflow is not complete on non-root phones.

Rooted Android pe chalta hai. Magisk ya KernelSU. App root maange to Allow.

Root module (Helper)

Helper is a root module (Magisk / KernelSU zip), not an APK. Installing it first is mandatory. Without the module the app can crash. Latest zip is on the Download page.

Helper zip pehle install karna mandatory hai. Bina module ke app crash ho sakti hai.

Spoofer

Mirage is an identity spoofer / engine: each profile gets unique IMEI / MEID, Android ID, Wi‑Fi / BT MAC, SIM serial, Google Ad-ID, model and build. Isolation is built in — no extra hide-list app. Educational use; follow local laws.

Har profile ke unique IDs. Extra hide-list app ki zarurat nahi. Local laws follow karo.

RTC (clock and timezone)

RTC here means the phone clock / timezone stay in sync with the profile GPS. If the location is New York, the time follows that region. GPS + timezone keep the profile consistent.

Clock / timezone profile GPS ke saath sync. Location ke mutabiq time.

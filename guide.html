How to install and use

Root, root module, spoofer setup, aur RTC — short official guide.

Install (4 steps)

01

Helper root module

Pehle Helper zip Magisk ya KernelSU me flash/install karo. Ye root module environment banata hai.

02

Mirage APK

v21.36 APK install karo (official app ke upar). Root permission allow karo.

03

Login / register

Account banao ya login karo. Profile save ho jana chahiye — email, status, expiry Profile pe dikhegi.

04

Create and switch

Bulk creator se profiles, target app select, floating widget se switch. Restore se backup wapas.

How to use

  1. App kholo, login/register.
  2. Bulk se profiles banao.
  3. Target app choose karo.
  4. Floating widget se profile badlo.
  5. Plan expire ho to Profile se expiry dekho, recharge ke baad full access.

Root

Mirage Spoofer rooted Android pe chalta hai. Magisk ya KernelSU dono supported. App root maange to Allow. Non-root phones pe ye app ka workflow complete nahi hota.

Root module (Helper)

Helper ek root module hai (Magisk / KernelSU zip), APK nahi. Pehle ye install karna mandatory hai. Module ke bina app crash ho sakti hai. Latest zip Download page pe hai.

Spoofer

Mirage ek identity spoofer / engine hai: har profile ke unique IMEI / MEID, Android ID, Wi‑Fi / BT MAC, SIM serial, Google Ad-ID, model aur build. Isolation inbuilt hai — extra hide-list app ki zarurat nahi. Educational use; local laws follow karo.

RTC (clock and timezone)

RTC yahan phone clock / timezone ko profile GPS ke saath sync karna hai. Location New York ho to time bhi us region ke mutabiq. GPS + timezone milke profile ko consistent rakhte hain.

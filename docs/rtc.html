RTC — clock and timezone

When a profile has a GPS location, Mirage Spoofer keeps RTC (clock) and timezone aligned with that region so apps do not see a mismatch.

Profile location ke hisaab se clock aur timezone sync.

Set or pick location on the map in the profile, save, then switch to that profile. Timezone follows the coordinates. Details and screenshots: guide RTC section.

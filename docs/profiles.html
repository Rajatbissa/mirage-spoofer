Profiles

Each profile is a saved identity (IMEI, Android ID, MAC, Ad-ID, and more). Bulk-create them, store in a group, assign a target app, switch from the widget.

Bulk banao, group me rakho, widget se switch.

  1. Home → Bulk Creator — set count (10 / 50 / 100+).
  2. Save into a group and pick the target app.
  3. Use the floating widget to switch without leaving that app.
  4. Backup / restore from Group settings if you need the same set later.

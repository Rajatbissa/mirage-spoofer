How to install Mirage Spoofer v21.38

Official order on rooted Android: Helper root module, reboot, APK, LSPosed scope, then allow root. The APK is the UI. The zip does the system work — restore, proxy, and background jobs.

Pehle Helper zip flash karo, reboot, phir v21.38 APK. LSPosed me module on. Root allow. Module skip kiya to crash ho sakti hai.

One rule: install the Helper zip before the APK. Mixing random mirrors or skipping the module is the usual reason the app dies on launch.

What you need

  • Android 9 or newer.
  • Working Magisk or KernelSU root (not a “root cloaker” APK from a random site).
  • LSPosed already installed on that root.
  • Files only from miragespoof.in or the GitHub v21.38 release — not Telegram forwards of unknown zips.

Why Helper comes first

Mirage Spoofer is two pieces. The APK lets you log in, edit profiles, and switch from Home or the floating widget. The Helper is the root module: it runs the Magisk / KernelSU side so restore, proxy connect, and ADB-style jobs can actually execute. If you only install the APK, you still have a UI — you do not have the engine.

Step 1 — Flash the Helper zip

Open Magisk or KernelSU. Install the official Helper zip from the download page. Reboot when the manager asks. After reboot, confirm the module is still enabled in the modules list. Magisk and KernelSU both work; pick the one your phone already uses. Do not flash an old Helper over a new APK or the other way around if the site lists a matching pair.

Step 2 — Install APK v21.38

Install Mirage_Spoofer_v21.38.apk over the current official app. Allow unknown sources if Android asks. Uninstall piracy or cracked APKs first — mixed signatures and leftover data cause login and crash loops. Package name is com.mirage.spoofer.

Step 3 — Enable in LSPosed

Open LSPosed Manager → Modules → Mirage Spoofer → on. Tick every target app in scope (select-all is often blocked). Reboot again if LSPosed asks. Full walkthrough: enable Mirage Spoofer in LSPosed.

Step 4 — First launch

Open Mirage Spoofer. Allow root when Magisk / KernelSU prompts. Login or register. Email, plan, and expiry sit on Profile. Create a profile or pick one, then switch from Home or the floating widget. Screenshots and widget notes: full guide.

If the app crashes or “does nothing”

  • Helper module enabled after reboot.
  • LSPosed shows Mirage on, and the target app is in scope.
  • You allowed root — not “deny” once and forgot.
  • Only the official APK, not a renamed clone.

Plan expiry is not a crash: Profile still opens so you can recharge. See the FAQ.

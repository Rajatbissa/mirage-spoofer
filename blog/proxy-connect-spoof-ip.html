Proxy connect, VPN tunnel, and spoof IP

Proxy connect is per profile: host, port, HTTP or SOCKS, optional login. When you switch to that profile the Helper turns the proxy on. A new profile starts with proxy off so credentials do not bleed.

Har profile ka proxy. Switch pe connect. IP GPS se nahi badalta.

Three names, one flow

  • Proxy connect — you bring the server; Mirage routes the target app.
  • VPN — the Helper can hide that tunnel so apps do not show a VPN flag. This is not a NordVPN-style plan.
  • Spoof IP — apps see the proxy exit address, not home Wi-Fi or SIM IP.

Match proxy country with location and timezone so GPS, clock, and IP sit in one region. Helper + LSPosed required.

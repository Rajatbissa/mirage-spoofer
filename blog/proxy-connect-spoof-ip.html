Proxy connect, VPN tunnel, and spoof IP

You bring the proxy server. Mirage Spoofer turns it on per profile so target apps can spoof IP. This is not a sold VPN subscription like NordVPN — Helper routes your proxy, optionally through a hidden tunnel.

Profile pe host, port, type, optional login. Switch pe Helper proxy on. Nayi profile pe proxy off. Public IP GPS se nahi badalta.

Proxy connect

On the profile, enter host, port, HTTP or SOCKS, optional user and pass, then enable proxy. Switch to that profile: Helper sends the on command. Leave the profile: proxy goes off. New profiles start with proxy disabled so old credentials do not bleed into a fresh identity. Details: proxy connect.

Use a proxy you control or a provider you already pay for. Dead host, wrong port, or HTTP vs SOCKS mismatch is why “IP did not change” reports happen — not because the map pin failed.

VPN tunnel (hide transport)

The Helper can run that route through a tunnel and hide VPN transport from apps in LSPosed scope. Target apps should not show a generic “you are on a VPN” flag the way a consumer VPN app often does. It is still your proxy. See VPN.

Not included: Mirage does not sell you an IP. No built-in “US server list.” You paste the endpoint on the profile.

Spoof IP

Apps then see the proxy exit IP, not home Wi-Fi or SIM. Map GPS alone never changes public IP. Pair with location + timezone in the same country when you use all three. Page: spoof IP.

Checklist

  1. Helper module installed and enabled after reboot.
  2. Target app in LSPosed scope.
  3. Working proxy (you provide host / port / type).
  4. Switch the profile that has proxy on — do not test from a profile where proxy is off.
  5. GPS pin and timezone in the same region as that IP when you use all three.

If IP stays on home Wi-Fi

  • Confirm the profile actually has proxy enabled (new profiles default off).
  • Confirm Helper is running — without the zip, PROXY_ON never happens.
  • Force-stop the scoped app after switch, then open it again.
  • Test the same host:port from another client to prove the proxy itself works.

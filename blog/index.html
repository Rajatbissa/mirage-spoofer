How to install Mirage Spoofer v21.38

The APK is only the UI. Flash the official Helper zip on Magisk or KernelSU, reboot, then install the APK, then turn the module on in LSPosed and allow root. Skip the zip and restore, proxy, and background jobs can fail — the app can crash.

Enable Mirage Spoofer in LSPosed

Hooks run only inside apps you tick in scope. Module off, or the app missing from the list, means real IDs and GPS stay. Select-all is unreliable — tick each target, reboot, then switch the profile from Home or the widget.

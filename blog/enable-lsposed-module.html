Enable Mirage Spoofer in LSPosed

Hooks run only in apps you tick in scope. Module off, or the app missing from the list, means real IDs, GPS, and IP stay. This is the step people skip — then they say “nothing changed.”

LSPosed Manager me Mirage on karo, har target app tick karo, reboot. Scope ke bahar identity, location, proxy kuch nahi badlega.

Before LSPosed

Finish install: Helper zip, reboot, then APK v21.38. LSPosed itself must already run on Magisk or KernelSU. If LSPosed Manager does not open, fix that first — Mirage cannot hook without it. More context: LSPosed page.

Enable and scope

  1. Open LSPosed Manager → Modules.
  2. Find Mirage Spoofer. Turn it on.
  3. Open recommended / scope. Tick each target app one by one.
  4. Do not depend on select-all — LSPosed often blocks it, and you think everything is scoped when it is not.
  5. Reboot. Open Mirage Spoofer and allow root.
Scope is the list that matters. System apps, browsers, and games you did not tick keep the real device. That is by design.

After that

Switch the profile from Home or the floating widget, then open the scoped app. If the old identity sticks, force-stop that app once. Widget can switch without leaving the app, but a cold start is the clean test.

If hooks still miss

  • Module toggle is on after reboot (some builds reset it).
  • The exact package is ticked — not a look-alike clone.
  • Helper zip is installed; LSPosed alone is not the full stack.
  • You switched the Mirage profile before opening the app.

Spoof location with timezone

Mirage can spoof location on the map and keep RTC (clock and timezone) on the same pin. That is the point of this post — GPS and time in one region, not a map fake with yesterday’s India clock.

Map se location set karo, timezone / RTC on rakho. New York GPS ho to clock bhi us region ka. IP alag cheez hai — proxy se.

Why GPS and clock together

If the profile GPS is New York and the phone clock is still India Standard Time, many apps treat that as inconsistent. Keep GPS spoof and timezone spoof on together. The map picker can detect timezone from coordinates so you do not have to guess “America/New_York” by hand.

RTC here means the clock / timezone path Mirage uses with the location pin — not a separate consumer “fake GPS” toy. Short pages: spoof location · location + timezone · RTC docs.

How to set it

  1. Finish install and put the target app in LSPosed scope.
  2. Open the profile. Turn location / GPS spoof on.
  3. Search a city or tap the map. Save the pin.
  4. Leave timezone / RTC on. Do not clear timezone in hooks if GPS is on.
  5. Switch the profile from Home or the floating widget, then open the scoped app.
Check: after switch, a maps-style app in scope should show the pin — not your real street — and the clock should match that region.

Widget and profile switch

You do not need to kill the target app every time if the widget can switch the active profile. Switch first, then open or resume the scoped app. If the old location sticks, force-stop that app once and open it again after the switch.

What this does not do

Spoof location does not spoof IP. Public IP still needs proxy connect. When you use GPS, timezone, and proxy together, keep the pin, clock, and proxy exit in the same country. A US map with an India exit IP is the same class of mismatch as GPS vs clock.

Common mistakes

  • Target app not in LSPosed scope — you still see real GPS.
  • Timezone / RTC turned off while GPS is on.
  • Helper module missing, so some hooks never apply.
  • Expecting Wi-Fi / cell IP to follow the map pin.
